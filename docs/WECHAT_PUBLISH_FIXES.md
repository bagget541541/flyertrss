## 修复内容详解

### 1. 点评格式优化（llm_daily_gen.py SYSTEM_PROMPT）

**改进前**：
```
💬 点评：现象：用户反映...。判断：建议...。依据：帖子原文"..."。
```

**改进后**：
```
💬 点评：用户反映...，建议...。论坛反馈显示...。
```

**修改**（第54-84行）：
- 去掉"现象："、"判断："、"依据："显式标签
- 让三段话自然连贯成一个段落
- 依据仅为帖子标题时可省略
- 示例：`建行龙积分入账后自动按3:1兑换万象星，万象星换京东卡约350:1实际收益不亮眼，论坛实测反馈该卡不值得专门多办一张。`

### 2. 热门讨论统计数据修复（llm_daily_gen.py SYSTEM_PROMPT + _backfill_hot_list）

**问题根源**：LLM 生成的热门讨论榜单行没有包含 `（N回/N阅）` 数据

**修复步骤**：
1. 更新 SYSTEM_PROMPT（第71行概览行示例）让 LLM 直接生成统计数据
2. 增强 `_backfill_hot_list()` 函数（第328-364行）支持多策略标题匹配：
   - 精确匹配：标题完全相同
   - 前缀匹配：标题被截断或改写
   - 关键词匹配：特殊情况处理

**结果**：热门讨论榜单现在显示
```
1. **标题**（N回/N阅）[银行]
```
